# NORTHSTAR IPv4 Subnet Calculator

A Python-based IPv4 subnet calculator designed to strengthen networking fundamentals and programming skills.

## Project Overview

The goal of this project is to develop a networking tool for calculating and analyzing IPv4 subnet information through a user-friendly interface.

This project is part of my **NORTHSTAR Networking Portfolio** and supports my CCNA learning journey.

## Planned Features

- Network address calculation
- Broadcast address calculation
- Subnet mask and CIDR prefix
- First and last usable host addresses
- Number of usable hosts
- IPv4 address validation
- User-friendly interface
